# Habit Tracker Server

This is the **backend** of the Habit Tracker project. It provides APIs for managing **user habits** and **public habits**, including searching, filtering, updating, and marking habits as completed. Built with **Node.js**, **Express**, and **MongoDB**.

## Features

- **User Habits Management**: Create, read, update, and delete user habits.  
- **Public Habits**: View and search public habits shared by users.  
- **Search & Filter**: Search habits by title or keyword and filter by category.  
- **Update Habits**: Update habit details including title, description, category, time, and image.  
- **Completion Tracking**: Mark habits as completed and track streaks.  
- **Category Management**: Supports categories like Morning, Work, Fitness, Evening, Study.
